KPI tile for Início and Resultados. Figures are mono + tabular so columns of tiles align optically.

```jsx
<StatCard label="Confirmadas hoje" value="128" delta="+12,4%" deltaDirection="up" icon="calendar-check" />
<StatCard label="Taxa de confirmação" value="87,2" unit="%" accent footnote="Meta: 85%" />
```

Only one `accent` tile per row — the lime marks the metric the screen is about.
